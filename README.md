# أهل القرآن

تطبيق **ختم القرآن** التحفيزي، يعمل أوفلاين بالكامل بصور مصحف مجمع الملك فهد، مع ورد يومي وسلسلة أيام وكنز نبوي.

## التشغيل على الويب

بعد النشر يظهر التطبيق على GitHub Pages، ويمكن تثبيته على الهاتف والحاسوب من الزر داخل الصفحة أو من قائمة المتصفح: **تثبيت التطبيق**.

## التشغيل المحلي

```bash
flutter pub get
flutter run
```

للبناء الويب مع العمل دون إنترنت بعد أول زيارة:

```bash
flutter build web --release --pwa-strategy=offline-first
```
